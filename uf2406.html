Caso práctico

Un parking quiere controlar las entradas de vehículos. Existe una clase Parking con el método boolean registrarEntrada(String matricula), que devuelve true si hay plazas libres y registra el vehículo. El parking tiene una capacidad máxima de 50 plazas y en este momento están todas ocupadas.

Apartado 1 - Casos de prueba

Define tres casos de prueba para la función registrarEntrada (descripción, datos de entrada y resultado esperado): un caso positivo (hay plazas libres), un caso negativo (parking lleno) y un caso límite (matrícula vacía o nula).

Caso 1 (positivo)
Descripción: entrada con plazas libres disponibles.
Entrada: matricula = "1234ABC" (parking con huecos libres)
Esperado: registrarEntrada devuelve true (vehículo registrado).

Caso 2 (negativo)
Descripción: entrada cuando el parking está lleno.
Entrada: matricula = "5678XYZ" (parking a capacidad máxima)
Esperado: registrarEntrada devuelve false / error "Parking lleno".

Caso 3 (límite)
Descripción: entrada con matrícula vacía.
Entrada: matricula = ""
Esperado: registrarEntrada devuelve false, sin errores no controlados.

Apartado 2 - Casos de uso

Describe un diagrama de casos de uso sencillo con un actor «Conductor» y dos casos de uso: «Registrar salida» y «Calcular importe a pagar». Indica qué tipo de relación (include o extend) usarías entre ellos y por qué.

Actor «Conductor», con dos casos de uso: «Registrar salida» (caso base) y «Calcular importe a pagar». La relación es include: «Registrar salida» incluye siempre a «Calcular importe a pagar», porque cada vez que un vehículo sale hay que calcular el importe, sin excepción. Con extend sería un comportamiento opcional que solo se da en algunos casos, y aquí ocurre siempre.

Apartado 3 - Excepción propia y try/catch/finally

Escribe en Java el bloque try/catch/finally que gestionaría una excepción si un vehículo intenta entrar y el parking está lleno. Puedes crear una excepción propia ParkingLlenoException que extienda Exception.

public class ParkingLlenoException extends Exception {
    public ParkingLlenoException(String mensaje) { super(mensaje); }
}

// ... en el main o en el método que gestiona la entrada:
try {
    if (!parking.registrarEntrada(matricula)) {
        throw new ParkingLlenoException("Parking lleno, no se puede registrar la entrada");
    }
    System.out.println("Entrada registrada correctamente");
} catch (ParkingLlenoException e) {
    System.out.println("Error: " + e.getMessage());
} finally {
    System.out.println("Solicitud de entrada procesada.");
}

/* Salida esperada (parking lleno):
Error: Parking lleno, no se puede registrar la entrada
Solicitud de entrada procesada.
*/

Apartado 4 - Prueba unitaria con JUnit

Escribe una clase de prueba JUnit llamada ParkingTest con dos métodos de prueba para registrarEntrada: uno que compruebe el caso de plaza libre con assertTrue y otro que compruebe el caso de parking lleno con assertFalse.

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

public class ParkingTest {
    @Test
    public void entradaConPlazaLibre() {
        Parking parking = new Parking(50);
        assertTrue(parking.registrarEntrada("1234ABC"));
    }

    @Test
    public void entradaConParkingLleno() {
        Parking parking = new Parking(0);
        assertFalse(parking.registrarEntrada("5678XYZ"));
    }
}
