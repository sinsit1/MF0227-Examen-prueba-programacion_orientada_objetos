Caso práctico

Una peluquería quiere gestionar la reserva de citas de sus clientes. Existe una clase Agenda con el método boolean reservarCita(String cliente, String hora), que devuelve true si la hora solicitada está libre. Ya hay una cita reservada a las 10:00.

Apartado 1 - Casos de uso

Describe un diagrama de casos de uso sencillo con un actor «Cliente» y dos casos de uso: «Reservar cita» y «Cancelar cita». Indica qué tipo de relación (include o extend) usarías entre ellos y por qué.

Actor «Cliente», con dos casos de uso: «Reservar cita» (caso base) y «Cancelar cita». La relación es extend: «Cancelar cita» extiende a «Reservar cita», porque solo ocurre en un caso opcional (cuando el cliente ya no puede acudir) y no en todas las reservas. Con include sería una parte obligatoria del caso base, que aquí no lo es.

Apartado 2 - Casos de prueba

Define tres casos de prueba para la función reservarCita (descripción, datos de entrada y resultado esperado): un caso positivo, un caso negativo (hora ya ocupada) y un caso límite (hora vacía o nula).

Caso 1 (positivo)
Descripción: reserva de una hora libre.
Entrada: cliente = "Marta", hora = "12:00"
Esperado: reservarCita devuelve true (cita reservada).

Caso 2 (negativo)
Descripción: reserva de una hora ya ocupada.
Entrada: cliente = "Luis", hora = "10:00"
Esperado: reservarCita devuelve false / error "Hora ocupada".

Caso 3 (límite)
Descripción: reserva con la hora vacía.
Entrada: cliente = "Ana", hora = ""
Esperado: reservarCita devuelve false, sin errores no controlados.

Apartado 3 - Prueba unitaria con JUnit

Escribe una clase de prueba JUnit llamada AgendaTest con dos métodos de prueba para reservarCita: uno que compruebe el caso de hora libre con assertTrue y otro que compruebe el caso de hora ocupada con assertFalse.

import org.junit.jupiter.api.Test;
import static org.junit.jupiter.api.Assertions.*;

public class AgendaTest {
    private final Agenda agenda = new Agenda();

    @Test
    public void reservaHoraLibre() {
        assertTrue(agenda.reservarCita("Marta", "12:00"));
    }

    @Test
    public void reservaHoraOcupada() {
        assertFalse(agenda.reservarCita("Luis", "10:00"));
    }
}

Apartado 4 - Excepción propia y try/catch/finally

Escribe en Java el bloque try/catch/finally que gestionaría una excepción si el cliente solicita una hora ya ocupada. Puedes crear una excepción propia HoraOcupadaException que extienda Exception.

public class HoraOcupadaException extends Exception {
    public HoraOcupadaException(String mensaje) { super(mensaje); }
}

// ... en el main o en el método que gestiona la reserva:
try {
    if (!agenda.reservarCita(cliente, hora)) {
        throw new HoraOcupadaException("La hora " + hora + " ya está reservada");
    }
    System.out.println("Cita reservada correctamente");
} catch (HoraOcupadaException e) {
    System.out.println("Error: " + e.getMessage());
} finally {
    System.out.println("Solicitud de cita procesada.");
}

/* Salida esperada (hora = "10:00"):
Error: La hora 10:00 ya está reservada
Solicitud de cita procesada.
*/
