Caso práctico

Se quiere diseñar la base de datos relacional de una tienda online y consultarla desde Java.

Apartado 1 - Creación de tablas

Escribe la sentencia CREATE TABLE para dos tablas: PRODUCTOS (id_producto INT clave primaria, nombre VARCHAR(100), precio DECIMAL(8,2), id_categoria INT clave foránea que referencia a CATEGORIAS) y CATEGORIAS (id_categoria INT clave primaria, nombre VARCHAR(50)).

CREATE TABLE CATEGORIAS (
    id_categoria INT PRIMARY KEY,
    nombre       VARCHAR(50)
);

CREATE TABLE PRODUCTOS (
    id_producto  INT PRIMARY KEY,
    nombre       VARCHAR(100),
    precio       DECIMAL(8,2),
    id_categoria INT,
    FOREIGN KEY (id_categoria) REFERENCES CATEGORIAS(id_categoria)
);

Apartado 2 - Inserción de datos

Escribe una sentencia INSERT que añada una categoría y una sentencia INSERT que añada un producto relacionado con esa categoría.

INSERT INTO CATEGORIAS (id_categoria, nombre)
VALUES (1, 'Informática');

INSERT INTO PRODUCTOS (id_producto, nombre, precio, id_categoria)
VALUES (1, 'Portátil Dell', 799.99, 1);

Apartado 3 - Consulta con INNER JOIN

Escribe una consulta SELECT que muestre el nombre de cada producto junto con el nombre de su categoría, combinando ambas tablas mediante un INNER JOIN.

SELECT p.nombre, c.nombre
FROM PRODUCTOS p
INNER JOIN CATEGORIAS c ON p.id_categoria = c.id_categoria;

Apartado 4 - UPDATE y DELETE

Escribe una sentencia UPDATE que cambie el precio de un producto concreto (identificado por su id_producto) y una sentencia DELETE que elimine los productos de una categoría concreta.

UPDATE PRODUCTOS
SET precio = 649.99
WHERE id_producto = 1;

DELETE FROM PRODUCTOS
WHERE id_categoria = 1;

Apartado 5 - Acceso con JDBC

Escribe en Java una clase ProductoDAO con un método listarProductos() que, usando JDBC, se conecte a jdbc:mysql://localhost:3306/tienda (usuario admin, contraseña admin123), ejecute la consulta del apartado 3 y muestre por consola cada producto con su categoría. Debe cerrar los recursos y tratar la excepción SQLException.

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;

public class ProductoDAO {
    private static final String URL = "jdbc:mysql://localhost:3306/tienda";
    private static final String USUARIO = "admin";
    private static final String CLAVE = "admin123";

    public void listarProductos() {
        String sql = "SELECT p.nombre, c.nombre "
                   + "FROM PRODUCTOS p INNER JOIN CATEGORIAS c ON p.id_categoria = c.id_categoria";

        // try-with-resources: cierra ResultSet, Statement y Connection automáticamente
        try (Connection con = DriverManager.getConnection(URL, USUARIO, CLAVE);
             Statement st = con.createStatement();
             ResultSet rs = st.executeQuery(sql)) {

            while (rs.next()) {
                System.out.println(rs.getString(1) + " - " + rs.getString(2));
            }
        } catch (SQLException e) {
            System.out.println("Error de base de datos: " + e.getMessage());
        }
    }
}
