Caso práctico

Se quiere diseñar la base de datos relacional de un gimnasio y consultarla desde Java.

Apartado 1 - Creación de tablas

Escribe la sentencia CREATE TABLE para dos tablas: MONITORES (id_monitor INT clave primaria, nombre VARCHAR(50), especialidad VARCHAR(30)) y CLASES (id_clase INT clave primaria, nombre VARCHAR(100), horario VARCHAR(20), id_monitor INT clave foránea que referencia a MONITORES).

CREATE TABLE MONITORES (
    id_monitor   INT PRIMARY KEY,
    nombre       VARCHAR(50),
    especialidad VARCHAR(30)
);

CREATE TABLE CLASES (
    id_clase   INT PRIMARY KEY,
    nombre     VARCHAR(100),
    horario    VARCHAR(20),
    id_monitor INT,
    FOREIGN KEY (id_monitor) REFERENCES MONITORES(id_monitor)
);

Apartado 2 - Inserción de datos

Escribe una sentencia INSERT que añada un monitor y una sentencia INSERT que añada una clase impartida por ese monitor.

INSERT INTO MONITORES (id_monitor, nombre, especialidad)
VALUES (1, 'Carlos', 'Spinning');

INSERT INTO CLASES (id_clase, nombre, horario, id_monitor)
VALUES (1, 'Spinning', '09:00', 1);

Apartado 3 - Consulta con agregación

Escribe una consulta que muestre, para cada monitor, cuántas clases imparte (usa LEFT JOIN entre MONITORES y CLASES, agrupando por monitor con GROUP BY y contando con COUNT).

SELECT m.nombre, COUNT(c.id_clase) AS num_clases
FROM MONITORES m
LEFT JOIN CLASES c ON m.id_monitor = c.id_monitor
GROUP BY m.nombre;

Apartado 4 - UPDATE y DELETE

Escribe una sentencia UPDATE que cambie el horario de una clase concreta (identificada por su id_clase) y una sentencia DELETE que elimine las clases de un monitor concreto.

UPDATE CLASES
SET horario = '19:30'
WHERE id_clase = 1;

DELETE FROM CLASES
WHERE id_monitor = 1;

Apartado 5 - Acceso con JDBC

Escribe en Java una clase MonitorDAO con un método listarClasesPorMonitor() que, usando JDBC, se conecte a jdbc:mysql://localhost:3306/gimnasio (usuario coach, contraseña gym2024), ejecute una consulta con INNER JOIN entre CLASES y MONITORES mostrando por consola el nombre de la clase, su horario y el nombre del monitor. Debe cerrar los recursos y tratar la excepción SQLException.

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;

public class MonitorDAO {
    private static final String URL = "jdbc:mysql://localhost:3306/gimnasio";
    private static final String USUARIO = "coach";
    private static final String CLAVE = "gym2024";

    public void listarClasesPorMonitor() {
        String sql = "SELECT c.nombre, c.horario, m.nombre "
                   + "FROM CLASES c INNER JOIN MONITORES m ON c.id_monitor = m.id_monitor";

        // try-with-resources: cierra ResultSet, Statement y Connection automáticamente
        try (Connection con = DriverManager.getConnection(URL, USUARIO, CLAVE);
             Statement st = con.createStatement();
             ResultSet rs = st.executeQuery(sql)) {

            while (rs.next()) {
                System.out.println(rs.getString(1) + " (" + rs.getString(2) + ") - " + rs.getString(3));
            }
        } catch (SQLException e) {
            System.out.println("Error de base de datos: " + e.getMessage());
        }
    }
}
