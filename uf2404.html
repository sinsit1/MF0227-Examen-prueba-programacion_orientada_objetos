Caso práctico

Se pide diseñar en Java un pequeño sistema de facturación para un taller mecánico.

Apartado 1 - Excepción propia y clase Taller

Crea una excepción propia HorasInvalidasException (que extienda Exception) y una clase Taller con un atributo privado ArrayList<Reparacion> (composición/agregación, donde Reparacion es la clase que se define en el apartado 2). La clase Taller debe tener registrarReparacion(Reparacion r), que lanza la excepción si las horas de trabajo son ≤ 0, y calcularFacturacionTotal(), que recorre la lista sin comprobar el tipo concreto de cada reparación.

public class HorasInvalidasException extends Exception {
    public HorasInvalidasException(String mensaje) { super(mensaje); }
}

import java.util.ArrayList;

public class Taller {
    private ArrayList<Reparacion> reparaciones = new ArrayList<>();

    public void registrarReparacion(Reparacion r) throws HorasInvalidasException {
        if (r.getHorasTrabajo() <= 0) {
            throw new HorasInvalidasException(
                "horas no válidas para " + r.getCliente());
        }
        reparaciones.add(r);
    }

    public double calcularFacturacionTotal() {
        double total = 0;
        for (Reparacion r : reparaciones) {
            total += r.calcularCoste();   // polimorfismo
        }
        return total;
    }

    public ArrayList<Reparacion> getReparaciones() { return reparaciones; }
}

Apartado 2 - Clase abstracta Reparacion

Crea una clase abstracta Reparacion con los atributos privados cliente (String), matricula (String) y horasTrabajo (double), un constructor que los inicialice, sus métodos get/set y un método abstracto calcularCoste() que devuelva un double.

public abstract class Reparacion {
    private String cliente;
    private String matricula;
    private double horasTrabajo;

    public Reparacion(String cliente, String matricula, double horasTrabajo) {
        this.cliente = cliente;
        this.matricula = matricula;
        this.horasTrabajo = horasTrabajo;
    }

    public String getCliente() { return cliente; }
    public void setCliente(String cliente) { this.cliente = cliente; }
    public String getMatricula() { return matricula; }
    public void setMatricula(String matricula) { this.matricula = matricula; }
    public double getHorasTrabajo() { return horasTrabajo; }
    public void setHorasTrabajo(double horasTrabajo) { this.horasTrabajo = horasTrabajo; }

    public abstract double calcularCoste();
}

Apartado 3 - Clases ReparacionMecanica y ReparacionElectrica

Crea dos clases ReparacionMecanica y ReparacionElectrica que hereden de Reparacion (usando super en el constructor) y que sobrescriban calcularCoste(): ReparacionMecanica cobra 35 €/hora más 20 € fijos de gastos de taller; ReparacionElectrica cobra 45 €/hora sin gastos fijos. Además, ReparacionMecanica debe tener dos constructores: uno completo (cliente, matricula, horasTrabajo) y otro reducido (cliente, matricula) que asigne 2.0 horas por defecto reutilizando el constructor completo con this(...).

public class ReparacionMecanica extends Reparacion {
    public ReparacionMecanica(String cliente, String matricula, double horasTrabajo) {
        super(cliente, matricula, horasTrabajo);
    }

    public ReparacionMecanica(String cliente, String matricula) {   // sobrecarga
        this(cliente, matricula, 2.0);
    }

    @Override
    public double calcularCoste() { return getHorasTrabajo() * 35 + 20; }
}

public class ReparacionElectrica extends Reparacion {
    public ReparacionElectrica(String cliente, String matricula, double horasTrabajo) {
        super(cliente, matricula, horasTrabajo);
    }

    @Override
    public double calcularCoste() { return getHorasTrabajo() * 45; }
}

Apartado 4 - Sobrescribir toString()

Sobrescribe también el método toString() en las clases ReparacionMecanica y ReparacionElectrica para mostrar cliente, matrícula, horas trabajadas y coste.

// En ReparacionMecanica

Apartado 5 - Método main

En un método main, crea un Taller y registra una ReparacionMecanica de Juan Pérez (matrícula 1234ABC, 3 horas), una ReparacionElectrica de Marta López (matrícula 5678XYZ, 1.5 horas), una ReparacionMecanica de Pedro Gómez (matrícula 9999ZZZ) con el constructor reducido y una ReparacionElectrica de Luis Ruiz con horas de trabajo -2. Captura la excepción con try/catch mostrando un mensaje de error, imprime después las reparaciones de la lista y, por último, la facturación total.

public class Main {
    public static void main(String[] args) {
        Taller taller = new Taller();
        try {
            taller.registrarReparacion(new ReparacionMecanica("Juan Pérez", "1234ABC", 3));
            taller.registrarReparacion(new ReparacionElectrica("Marta López", "5678XYZ", 1.5));
            taller.registrarReparacion(new ReparacionMecanica("Pedro Gómez", "9999ZZZ"));
            taller.registrarReparacion(new ReparacionElectrica("Luis Ruiz", "4321CBA", -2));
        } catch (HorasInvalidasException ex) {
            System.out.println("Error: " + ex.getMessage());
        }
        for (Reparacion r : taller.getReparaciones()) {
            System.out.println(r);
        }
        System.out.println("Facturación total: " + taller.calcularFacturacionTotal());
    }
}
