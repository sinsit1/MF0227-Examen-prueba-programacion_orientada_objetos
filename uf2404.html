Caso práctico

Se pide diseñar en Java un pequeño sistema de gestión de nóminas de una empresa.

Apartado 1 - Clase abstracta Empleado

Crea una clase abstracta Empleado con los atributos privados nombre (String), dni (String) y salarioBase (double), un constructor que los inicialice, sus métodos get/set y un método abstracto calcularSalario() que devuelva un double.

public abstract class Empleado {
    private String nombre;
    private String dni;
    private double salarioBase;

    public Empleado(String nombre, String dni, double salarioBase) {
        this.nombre = nombre;
        this.dni = dni;
        this.salarioBase = salarioBase;
    }

    public String getNombre() { return nombre; }
    public void setNombre(String nombre) { this.nombre = nombre; }
    public String getDni() { return dni; }
    public void setDni(String dni) { this.dni = dni; }
    public double getSalarioBase() { return salarioBase; }
    public void setSalarioBase(double salarioBase) { this.salarioBase = salarioBase; }

    public abstract double calcularSalario();
}

Apartado 2 - Clases Gerente y Operario

Crea dos clases Gerente y Operario que hereden de Empleado (usando super en el constructor) y que sobrescriban calcularSalario(): Gerente = salarioBase + 20% de bonus, Operario = salarioBase sin bonus. Además, Gerente debe tener dos constructores: uno completo (nombre, dni, salarioBase) y otro reducido (nombre, dni) que asigne un salarioBase por defecto de 1500.0 reutilizando el constructor completo con this(...).

public class Gerente extends Empleado {
    public Gerente(String nombre, String dni, double salarioBase) {
        super(nombre, dni, salarioBase);
    }

    public Gerente(String nombre, String dni) {   // sobrecarga
        this(nombre, dni, 1500.0);
    }

    @Override
    public double calcularSalario() { return getSalarioBase() * 1.20; }
}

public class Operario extends Empleado {
    public Operario(String nombre, String dni, double salarioBase) {
        super(nombre, dni, salarioBase);
    }

    @Override
    public double calcularSalario() { return getSalarioBase(); }
}

Apartado 4 - Excepción propia y Empresa

Crea una excepción propia SalarioInvalidoException (que extienda Exception) y una clase Empresa con un atributo privado ArrayList<Empleado> (composición/agregación). Debe tener contratar(Empleado e), que lanza la excepción si el salario base es ≤ 0, y calcularNominaTotal(), que recorre la lista sin comprobar el tipo concreto de cada empleado.

public class SalarioInvalidoException extends Exception {
    public SalarioInvalidoException(String mensaje) { super(mensaje); }
}

import java.util.ArrayList;

public class Empresa {
    private ArrayList<Empleado> empleados = new ArrayList<>();

    public void contratar(Empleado e) throws SalarioInvalidoException {
        if (e.getSalarioBase() <= 0) {
            throw new SalarioInvalidoException(
                "salario no válido para " + e.getNombre());
        }
        empleados.add(e);
    }

    public double calcularNominaTotal() {
        double total = 0;
        for (Empleado e : empleados) {
            total += e.calcularSalario();   // polimorfismo
        }
        return total;
    }

    public ArrayList<Empleado> getEmpleados() { return empleados; }
}

Apartado 5 - Método main

En un método main, crea una Empresa y añade un Gerente Laura (12345678A, 2500), un Operario Marcos (87654321B, 1200), un Gerente Sonia con el constructor reducido y un Operario Pedro con salario base -100. Captura la excepción con try/catch mostrando un mensaje de error, imprime después los empleados de la lista y, por último, la nómina total.

public class Main {
    public static void main(String[] args) {
        Empresa empresa = new Empresa();
        try {
            empresa.contratar(new Gerente("Laura", "12345678A", 2500));
            empresa.contratar(new Operario("Marcos", "87654321B", 1200));
            empresa.contratar(new Gerente("Sonia", "11223344C"));
            empresa.contratar(new Operario("Pedro", "99887766D", -100));
        } catch (SalarioInvalidoException ex) {
            System.out.println("Error: " + ex.getMessage());
        }
        for (Empleado e : empresa.getEmpleados()) {
            System.out.println(e);
        }
        System.out.println("Nómina total: " + empresa.calcularNominaTotal());
    }
}
